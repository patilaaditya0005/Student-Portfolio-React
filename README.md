# 🌐 Student Portfolio — Aaditya Patil

A modern, responsive, and interactive personal portfolio built with **React, Vite, JavaScript, and CSS**. Designed to showcase my background, technical skills, academic journey, and projects through a clean and engaging user experience.

The portfolio serves as a central place to explore my work, learn about my technical interests, and connect with me.

---

## ✨ Features

- **🏠 Home** — Introduction and overview of my portfolio.
- **👨‍💻 About Me** — Personal background, interests, and professional introduction.
- **🎓 Education** — Academic journey and educational details.
- **⚡ Skills** — Technical skills and areas of expertise.
- **🚀 Projects** — Showcase of selected projects with supporting images and demonstration media.
- **📩 Contact** — Contact section with an email-based communication option.
- **📱 Responsive Design** — Layout designed for desktop, tablet, and mobile screens.
- **🎨 Modern UI** — Clean visual presentation with interactive elements and thoughtful styling.
- **🧩 Reusable Components** — React-based component structure for organized development.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone https://github.com/patilaaditya0005/Student-Portfolio-React.git
```

### 2. Navigate to the project directory

```bash
cd Student-Portfolio-React
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal (usually `http://localhost:5173`) to explore the portfolio.

### 5. Create a production build

```bash
npm run build
```

The optimized production files will be generated in the `dist/` directory.
