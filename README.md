# 🌐 Student Portfolio Website

A modern, responsive personal portfolio website built with **HTML, CSS, and JavaScript** to showcase my profile, technical skills, education, projects, and contact information.

The portfolio provides a central place to explore my background, review my work, and connect with me.

## ✨ Features

- **Home Page** — A welcoming introduction and portfolio overview.
- **About Me** — Personal introduction and background.
- **Education** — Academic journey and educational details.
- **Skills** — Technical skills and areas of expertise.
- **Projects** — Project showcase with supporting media.
- **Contact Page** — A dedicated page for getting in touch.
- **Responsive Design** — Designed to provide a usable experience across different screen sizes.
- **Interactive Elements** — JavaScript-powered functionality and user interactions.
- **Visual Assets** — Profile images and additional project-related imagery.
- **Project Demo Video** — Includes a video demonstration of the project.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/patilaaditya0005/Student-Portfolio-Javascript.git
```

### 2. Open the project

```bash
cd Student-Portfolio-Javascript
```

### 3. Run the website

Open `index.html` in your web browser.

For a smoother development experience, you can also use the **Live Server** extension in Visual Studio Code.
